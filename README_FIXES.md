# Исправления проверки проекта

- Загрузка отклоняет файлы, сигнатура которых не соответствует заявленному типу JPEG, PNG или WebP. Расширение сохранённого файла определяется по типу, а не имени, присланному клиентом.
- Добавлена проверка поддельного содержимого и опасного расширения в API-тесте.

Проверка сигнатуры не является полной проверкой корректности изображения. Реальный inference, авторизация и проверка внешнего API 2ГИС в рамках этого исправления не реализованы.
