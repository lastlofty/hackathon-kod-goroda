# Исправления проверки проекта

## Повторная проверка актуального main

- Исправлен порядок импортов в роутере API. Ruff на версии `b105cb0` сообщал `I001`.
- На локальном Docker Compose проверены запуск PostgreSQL и backend, а также `GET /health` и `GET /api/v1/inspection/frames?workspace=mgts`. Последний вернул пустые коллекции для новой базы, как предусмотрено обработчиком.
- В браузере проверены загрузка интерфейса, смена маршрута, отображение снимков и карточек, переход из реестра к объекту на карте и открытие настроек 2ГИС.
- Тесты: `pytest -q` — 11 passed, `node --test tests/test_drive.cjs` — 3 passed, `ruff check .` — без ошибок после исправления.

Для фактической загрузки тайлов MapGL и запроса Routing API требуется действующий ключ Map Tiles API и Routing API. В настройках проверяемого браузера ключ отсутствовал, поэтому эти внешние вызовы не подтверждены.

- Загрузка отклоняет файлы, сигнатура которых не соответствует заявленному типу JPEG, PNG или WebP. Расширение сохранённого файла определяется по типу, а не имени, присланному клиентом.
- Добавлена проверка поддельного содержимого и опасного расширения в API-тесте.
- Создание и изменение медиа проверяют, что широта и долгота заданы вместе. При изменении учитываются уже сохранённые координаты. Обязательные поля медиа отклоняют явный null с кодом 422.
- Локальный .env исключён из индекса Git. Ранее сохранённый в истории ключ следует отозвать и заменить у поставщика.

Проверка сигнатуры не является полной проверкой корректности изображения. Реальный inference, авторизация и проверка внешнего API 2ГИС в рамках этого исправления не реализованы.
